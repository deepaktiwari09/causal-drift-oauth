Privacy Policy

This policy explains how Causal Drift Analytics accesses, uses, stores, shares, protects, and deletes Google and YouTube user data.

1. Application and operator

Causal Drift Analytics is a local-first analytics application operated by Deepak Kumar Tiwari. Questions or deletion requests can be sent to deepaktiwari3020@gmail.com.

2. Google and YouTube data accessed

The application uses YouTube API Services and may request these read-only OAuth scopes:

  • youtube.readonly to read authorized channel, video, playlist, caption, and engagement metadata exposed by the YouTube Data API.
  • yt-analytics.readonly to read YouTube Analytics reports for content owned by the authorizing user.

Depending on enabled features, the application may process channel and video identifiers, titles, descriptions, tags, publishing timestamps, thumbnails, public engagement counters, comments, caption metadata, watch-time metrics, audience-retention metrics, traffic-source dimensions, geography, device dimensions, and subscriber gains or losses where the API makes them available.

The application does not request or store the user's Google or YouTube password.

3. How the data is used

Authorized data is used only to provide visible content-intelligence features to the channel owner, including publishing-slot analysis, performance trends, content insights, findings, experiment comparisons, and per-video scorecards.

Google user data is not used for targeted advertising, generalized advertising, credit decisions, surveillance, or training public or shared machine-learning models.

4. Storage and security

Normalized analytics data and derived insights are stored in a PostgreSQL database on infrastructure controlled by the operator and available only on the operator's local network. Access is restricted to authorized devices and users.

Composio is used as an integration provider for OAuth authorization and API execution. OAuth access and refresh tokens are managed by Composio and are not published in this website or committed to the application's source repository.

This public policy website does not use advertising trackers, analytics scripts, account registration, or cookies.

5. Sharing and transfers

Google and YouTube user data is not sold or shared with data brokers, advertising platforms, or unrelated third parties. Data is transmitted only to service providers necessary to deliver the application—Google/YouTube and Composio—or when required for security or by applicable law.

6. Retention, revocation, and deletion

Analytics data is retained only while it is needed to provide historical comparisons and while authorization remains active. The application will verify at least every 30 days that access remains authorized.

The user can revoke access from the Google Account connections page or request deletion by emailing deepaktiwari3020@gmail.com. Following a verified deletion request or loss of authorization, associated authorized data will be deleted within 30 days unless retention is required by law.

7. User control and policy changes

The authorizing user controls whether the application can access their YouTube data. If the application materially changes the data it accesses or how that data is used, this policy will be updated and the user will be asked to provide renewed consent before the new use begins.

8. Google API Limited Use

Causal Drift Analytics' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Use of YouTube information is also governed by the YouTube Terms of Service, Google Privacy Policy, and YouTube API Services Developer Policies.

9. Contact

For privacy questions, access concerns, or deletion requests, email deepaktiwari3020@gmail.com.
