Causal Drift Analytics is a private dashboard for an authorized channel owner. It turns YouTube channel and analytics data into publishing-slot analysis, content insights, findings, and per-video scorecards.

The dashboard runs on the operator's local network. This public site contains product and privacy information only.

01

Read-only by design

The application requests the minimum permissions needed to read channel metadata and YouTube Analytics reports.

02

Owner-controlled storage

Analytics data is stored in a local PostgreSQL database on infrastructure controlled by the channel owner.

03

No advertising use

Google user data is not sold, used for advertising, or shared with data brokers.

Google API disclosure

Transparent access and control

Causal Drift Analytics uses YouTube API Services. Its use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
